# Flight-Trajectory-Conflict-Resolution
A comprehensive collision avoidance algorithm in Python, intended for resolving level conflicts between two aircraft. This project presents a single-aircraft turn algorithm, a process for turning back to resume the original flight plan, and a random scenario generator to ensure robustness. The calculations for heading changes are based on the assumption of negligible turn delay for the aircraft.
For a demo of the algorithm in action, check out the demonstration videos, for both a left and right turn.
